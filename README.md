## Produto escolhido

**Phantom Hair**, uma tinta temporária para pelos invisíveis. O produto é fictício: a fórmula é espalhada sobre pelos de barba, braços ou pernas e os disfarça, criando o visual de pele depilada em minutos, sem lâminas e sem dor. Para voltar ao normal, basta tomar um banho com água e sabonete. A página tenta convencer o visitante de que ele precisa de um "efeito de pele lisa" que dura só até o próximo banho.

## Tecnologias utilizadas

- HTML5
- CSS3 (Grid, Flexbox, animações e media queries)
- JavaScript puro (sem frameworks)
- Font Awesome 6 via CDN (ícones)
- Google Fonts (Archivo e Roboto)

## Funcionalidades interativas

1. Menu responsivo que abre e fecha no mobile
2. Scroll suave entre as seções
3. Navbar fixa no topo durante a rolagem
4. Efeitos hover em botões, links e cards
5. Animação CSS de entrada no hero
6. Botão CTA "Comprar agora" com resposta na tela
7. FAQ em formato acordeão

## Como executar localmente

1. Clone o repositório:
   git clone https://theorodriguesldo.github.io/phantom-hair/
2. Entre na pasta do projeto:
   cd phantom-hair
3. Abra o arquivo `index.html` no navegador (duplo clique) ou use a extensão **Live Server** do VS Code.

Não há dependências para instalar. O projeto precisa de internet apenas para carregar os ícones (Font Awesome) e as fontes (Google Fonts).
